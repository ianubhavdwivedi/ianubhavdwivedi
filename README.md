## Featured Project

### [PromptCheck — AI Prompt Quality Analyzer](projects/promptcheck/README.md)

A lightweight, dependency-free Python tool that reviews AI prompt templates for common quality and safety concerns. It runs locally, uses static checks, and does not send prompt text to an external service.

- Detects common instruction-override patterns and possible credential mentions
- Flags prompts that may need clearer goals or output guidance
- Includes unit tests and a GitHub Actions test workflow

**Note:** PromptCheck is a static review aid, not an AI model or a guarantee of prompt safety.
